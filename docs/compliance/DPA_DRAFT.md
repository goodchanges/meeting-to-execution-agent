# Data processing agreement draft

Unsigned and subject to legal review.

- Identify the controller and processor, parties, contacts and term.
- Specify processing instructions, transcript and activity categories, data subjects, duration and purpose.
- List subprocessors, locations, notice and transfer safeguards.
- Attach verified technical and organizational measures. Define security notifications, assistance, audits and access.
- Set deadlines for rights requests, return/deletion, backup expiry and residual audit records. Account for independently retained GitHub issues.
