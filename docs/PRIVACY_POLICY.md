# Privacy policy draft

Requires legal review before commercial use.

MeetFlow processes account details, meeting transcripts, participants, evidence, approvals and task records. Upload content only with permission. In live mode, OpenAI receives transcript segments and comparison evidence. Confirmed GitHub issue creation sends the task, source meeting metadata and quoted evidence to the configured repository. The configured email provider delivers reset links.

Account deletion removes owned records from the active database. Pseudonymous audit records and external GitHub issues remain. Backups expire under the operator's retention policy. Before publication, add the operator's identity and contact, actual retention periods, applicable rights and request procedures, and transfer information.
